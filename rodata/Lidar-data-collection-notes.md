# Lidar data collection notes

# Run 0
- Robot is in a confined space (roughly 6-9 m^2)
- Lidar is partially obstructed in rearward facing direction by load carried by the robot

# Run 1
- Robot is in a confined space
- Lidar is not obstructed
- Robot collides with an object which it failed to recognize

# Run 2
- Robot is in a confined space
- Lidar is not obstructed
- equivalent to run 0 but without carrying a load

# Run 3
- Robot is in a confined space
- Lidar is not obstructed
- very long run time

# Run 4
- Robot is in a very tightly confined space (barely any forward motion possible)
- Lidar is not obstructed

# Run 5
- Robot is in a rectangular office room
- Lidar is not obstructed

# Run 6
- Robot is in a rectangular office room
- Lidar is not obstructed
- Robot makes large turns 

# Run 7
- Robot is in a large hallway
- Lidar is not obstructed
- Robot makes large turns
- Robot is not under lab conditions and is therefore occassionally repositioned for safety reasons

# Run 8
- Robot is in an office room
- Lidar is partially obstructed, but used continuously instead of sporadically leading to very poor measurement quality
- Robot travels along a rectangular path
